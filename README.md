# CodeAlpha_LanguageTranslator
Language Translation Tool built for the CodeAlpha AI Internship (Task 1).

## Features
- Enter text, choose source (or auto-detect) and target language
- Uses Google Translate through the `deep-translator` library
- Copy button (code block) and text-to-speech (gTTS)

## Run
```
pip install -r requirements.txt
streamlit run app.py
```
Internet connection is required.
